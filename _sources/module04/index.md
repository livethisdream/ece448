# Module 4 — Digital Modulation

::::{frame}
:class: title-frame

<div class="course-mark">ECE 448 · Module 04</div>

<h1 class="frame-title">Digital Modulation</h1>

<div class="title-rule"></div>

From bits to waveforms and back: FSK and PAM, end to end.

Lessons 8–10 · Software Defined Radios · Dr. Neil Rogers
::::

::::{frame} Where This Module Goes
FSK and PAM from the flowgraph up: pulse shaping, matched filtering, and timing recovery, finishing with a link that carries ASCII text.
::::

::::{frame} Learning Objectives

<ol class="lo-list" style="--module: '4'">
  <li>I can describe FSK modulation and implement an FSK transmitter and receiver in GNU Radio.</li>
  <li>I can describe PAM theory and identify the pulse-shaping, symbol-rate, and bandwidth trade-offs.</li>
  <li>I can apply matched filtering and symbol-timing recovery to a received PAM signal.</li>
  <li>I can implement a PAM link that transmits and receives ASCII text end-to-end.</li>
</ol>
