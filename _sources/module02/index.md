::::{frame}
:class: title-frame

<div class="course-mark">ECE 448 · Module 02</div>

<h1 class="frame-title">SDR &amp; GNU Radio Foundations</h1>

<div class="title-rule"></div>

The radio is software now. Meet the hardware, then build your first flowgraph.

Lessons 4–5 · Software Defined Radios · Dr. Neil Rogers
::::

::::{frame} Where This Module Goes
What is inside an SDR, how sample rate and bandwidth trade, and your first GNU Radio flowgraphs against real captured signals.
::::

::::{frame} Learning Objectives

<ol class="lo-list" style="--module: '2'">
  <li>I can describe what a Software Defined Radio is, contrast it with a traditional hardware radio, and identify the SDR used in this course, the PlutoSDR.</li>
  <li>I can identify the roles of the RF frontend, ADC/DAC, and host in an SDR signal chain and describe sample-rate, bandwidth, and dynamic-range trade-offs.</li>
  <li>I can install GNU Radio and use GNU Radio Companion (GRC) to build, inspect, and run a basic flowgraph.</li>
  <li>I can capture a real RF signal using an SDR and interpret its time- and frequency-domain representations.</li>
</ol>
