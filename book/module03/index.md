# Module 3 — Analog Modulation

::::{frame}
:class: title-frame

<div class="course-mark">ECE 448 · Module 03</div>

<h1 class="frame-title">Analog Modulation</h1>

<div class="title-rule"></div>

AM and FM: build them, receive them, and hear the difference.

Lessons 6–7 · Software Defined Radios · Dr. Neil Rogers
::::

::::{frame} Where This Module Goes
Simulate AM, then build AM and FM receivers in GNU Radio and pull a live broadcast station, RDS data included, off the air.
::::

::::{frame} Learning Objectives

<ol class="lo-list" style="--module: '3'">
  <li>I can describe DSB-AM, DSB-SC, and SSB and identify each on a spectrum.</li>
  <li>I can implement an AM modulator and demodulator in GNU Radio and verify demodulated audio against the source.</li>
  <li>I can implement an FM receiver in GNU Radio, demodulate a live broadcast FM signal, and decode its RDS data.</li>
  <li>I can explain and demonstrate the trade-off between bandwidth and noise performance for AM vs. FM.</li>
</ol>
