    Module 4 — Digital Modulation#

    ECE 448 · Module 04

    Digital Modulation

    From bits to waveforms and back: FSK and PAM, end to end.

    Lessons 8–10 · Software Defined Radios · Dr. Neil Rogers

    Where This Module Goes

    FSK and PAM from the flowgraph up: pulse shaping, matched filtering, and timing recovery, finishing with a link that carries ASCII text.

    Learning Objectives

    1. I can describe FSK modulation and implement an FSK transmitter and receiver in GNU Radio.
    2. I can describe PAM theory and identify the pulse-shaping, symbol-rate, and bandwidth trade-offs.
    3. I can apply matched filtering and symbol-timing recovery to a received PAM signal.
    4. I can implement a PAM link that transmits and receives ASCII text end-to-end.
