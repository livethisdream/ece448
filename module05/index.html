    Module 5 — Custom Blocks & Midterm#

    ECE 448 · Module 05

    Custom Blocks & Midterm

    When GNU Radio does not have the block, write it.

    Lesson 11 · Software Defined Radios · Dr. Neil Rogers

    Where This Module Goes

    Out-of-tree modules and custom Python blocks, then the midterm: a fox hunt for a hidden transmitter and a capture-the-flag.

    Learning Objectives

    1. I can create a GNU Radio out-of-tree (OOT) module and add a custom Python block to it.
    2. I can implement a custom signal-processing block from scratch and integrate it into a GNU Radio flowgraph.
    3. I can find a hidden transmitter in a direction-finding fox hunt using an SDR and a directional antenna.
    4. I can solve capture-the-flag challenges that require finding, capturing, demodulating, and decoding unknown signals with GNU Radio.

    In This Module

    Lesson · L11

    Out-of-Tree Modules and Custom Blocks

    Package a GNU Radio out-of-tree module and write your own Python block. Objectives 5.1, 5.2.

     L11 Lab

    Custom Block

    Write a custom block and use it in a working flowgraph. Objectives 5.1, 5.2.

     Midterm

    Fox Hunt and CTF

    A direction-finding fox hunt for a hidden transmitter, and a capture-the-flag. Objectives 5.3, 5.4.
